
# Gestión de Contactos

Aplicación de escritorio desarrollada en Java Swing mediante Apache NetBeans, utilizando el patrón Modelo-Vista-Controlador (MVC).

## Funcionalidades

- Agregar, modificar y eliminar contactos.
- Buscar y ordenar contactos.
- Clasificar contactos por categorías.
- Marcar contactos como favoritos.
- Exportar contactos a archivos CSV.
- Manejar eventos de teclado y mouse.
- Visualizar estadísticas de contactos.
- Mostrar el estado de carga mediante una barra de progreso.

## Tecnologías utilizadas

- Java
- Java Swing
- Apache NetBeans
- Maven
- CSV

## Estructura del proyecto

- Modelo: persona.java y personaDAO.java
- Vista: ventana.java
- Controlador: logica_ventana.java

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en Apache NetBeans.
3. Compilar el proyecto.
4. Ejecutar la clase vista.ventana.
